Encrypted archive data is hosted separately from this Tumblr reader.

Annotations & persistence

Your Canon / Reference / Non-canon labels, saved passages, and notes are stored separately from the archive text.

On this cloud reader they live in this browser’s localStorage. That normally survives closing and reopening the site in the same browser, but it is not a safe long-term backup and it does not automatically sync between devices.

Export annotations downloads a tiny JSON backup. Later, when we rebuild the archive from newer ChatGPT exports, those annotations can be re-applied using stable account + message IDs.

Read branch uses the original parent/child graph in your ChatGPT export. If a turn has multiple continuations, the reader shows them instead of pretending there is only one correct “next” turn.
